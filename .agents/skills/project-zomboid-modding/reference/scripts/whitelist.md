
# whitelist

- **Soft Override:** Unknown

Whitelists a fluid to be allowed to put inside a [fluid container ](https://pz-wiki-modding.github.io/PZ-API-Docs/scripts/component/component_fluidcontainer.html).

## Hierarchy

This block can be a child of the following blocks:

- [component FluidContainer ](#scripts-component-fluidcontainer)

ID
--

This block should have no ID.

## Parameters

### `fluid`

- **Type:** string

A fluid which is allowed to be put inside this fluid container.
