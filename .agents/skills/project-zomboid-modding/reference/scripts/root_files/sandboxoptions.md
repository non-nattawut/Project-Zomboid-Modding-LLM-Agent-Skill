
# ROOT-SandboxOptions

- **Soft Override:** Unknown

- **Is Root:** True

- **Root patterns:** `media\/sandbox-options\.txt$`

The root of a sandbox options file. The file should be stored in the following path:

```

📁 media
  📄 sandbox-options.txt

```

You can find more information about sandbox options [here ](https://pzwiki.net/wiki/Sandbox_options).

## Hierarchy

## Parameters

### `VERSION`

- **Type:** Unknown

- **Required:** True

- **Allowed values:** `1`

The version of the handler of the sandbox options. Keep this equal to 1.
